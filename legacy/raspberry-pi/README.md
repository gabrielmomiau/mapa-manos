# Prototipo Raspberry Pi archivado

Esta carpeta conserva la implementación original con FastAPI, OpenCV, MediaPipe para Python,
Picamera2, WebSocket, persistencia de capturas en disco y correo SMTP.

No forma parte de la aplicación estática ni del artefacto publicado en GitHub Pages. Se mantiene
únicamente como referencia histórica y para recuperar alguna integración de hardware en el futuro.

Las rutas del README y los guiones originales correspondían a la antigua raíz del repositorio y no
se han actualizado.
